# StudyRAG · demo online

Demo di StudyRAG con dati di esempio già caricati: si prova senza installare niente.
Materie, caricamenti, AI, backup ed esportazioni sono disattivati; il resto (piano di studio, agenda, libretto/voti,
mappe, quiz e flashcard di esempio) funziona.

Avvio in locale: `pip install -r requirements.txt` e poi `streamlit run streamlit_app.py`.
Versione completa: studyrag.supporto@gmail.com
